# S&Box - Destiny 2 Map Importer
- Imports ripped Destiny 2 maps from **[Charm]([https://github.com/DeltaDesigns/CharmBox](https://github.com/MontagueM/Charm/tree/delta/EOF))** into your S&Box scene
 
## Requirements
1. Have a map ripped using Charm (Hopefully you know how to do this if you're using this tool)
2. Have all your materials, shaders and models in your projects 'Assets' folder ([Guide]([https://github.com/DeltaDesigns/Charm/wiki/Source-2-Importing](https://github.com/DeltaDesigns/Charm/wiki/S&Box-Importing)))
## How to install

1. Download the source code for this and use it as a base for your project.
2. In the scene editor, make a new scene.
3. Select "Import Destiny Map" from the tool bar, adjust settings if needed, then "Select Files"
4. Navigate to where the maps "info.cfg" files are located and select everything you want to import
5. Wait, this may take some time!

Tip: Once you have your shaders in your project folder, you can click 'Importer Debug->Shaders->Compile All Shaders' to work around a current [bug](https://github.com/Facepunch/sbox-issues/issues/9126)
